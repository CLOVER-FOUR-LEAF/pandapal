## 2. 数据格式（A1 按此产出，A2/A3/A4 按此读写）

### 2.1 `graph.json`（成长图谱）
```json
{
  "version": 1,
  "nodes": [{
    "id": "piano",                    // ascii slug，唯一，[a-z0-9_]
    "label": "钢琴",                   // 中文名，唯一
    "domain": "aesthetics",           // ethics|intellect|health|aesthetics|labor
    "type": "interest",               // interest|event|goal|health|person|trait|affair
    "status": "dropped",              // active|dropped|done
    "first_seen": "2024-03-01",
    "last_seen": "2026-10-02",
    "weight": 3,                      // 提及次数，>=1
    "private": false,                 // true=悄悄话，家长视角隐藏
    "facts": [{"date": "2024-03-01", "text": "学了三个月，坐不住放弃了"}]
  }],
  "edges": [{
    "source": "save_money", "target": "new_pc", "rel": "为了", "since": "2026-09-30", "weight": 1
  }]
}
```
- domain：德=ethics 智=intellect 体=health 美=aesthetics 劳=labor。
- 边必须双向存在合理（source/target 都必须是已存在的 node id）。
- 关系词只用这几个：`为了`、`联想到`、`导致`、`一起`、`属于`、`来自`。

### 3.2 `server/graph.py`（A2）
```python
class GraphStore:
    def __init__(self, child_dir: Path)
    @property path -> Path                              # child_dir/"graph.json"
    def load(self) -> dict                              # 缺文件返回 {"version":1,"nodes":[],"edges":[]}
    def export(self, view: str = "child") -> dict       # view="parent" 时剔除 private 节点及其边
        # 返回 {"nodes":[{"id","label","domain","type","status","first_seen","last_seen","weight","private","facts"}],
        #        "edges":[{"source","target","rel","since","weight"}]}
    def brief_block(self, limit: int = 40) -> str       # 供 prompt 注入的紧凑摘要，<=900 字
    def recall(self, query: str, limit: int = 4) -> dict
        # {"nodes":[{"id","label","domain","status","score"}],  按 score 降序
        #  "edges":[{"source","target","rel"}],                 命中的一跳关联边
        #  "block": "【换电脑】…\n【攒钱】…"}                     直接塞进 prompt 的文本
        # 规则：bigram 命中 label/related/facts 得分；再沿边扩一跳（权重降半）；不返回 private 节点
    def merge(self, data: dict) -> dict
        # data: {"nodes":[{"label","domain","type","status","fact"}], "edges":[{"source","target","rel"}]}
        # source/target 可给 label 名（自动转 id）。同 label 视为同一节点：合并事實、更新 last_seen/weight/status
        # 返回 {"added_nodes":[{"id","label","domain"}], "added_edges":[{"source","target","rel"}],
        #        "updated":[{"id","label"}]}
```

## 5. 对话流 SSE 事件（后端 A4 发，前端 A7 收）

保留 `mode`/`token`/`plan`/`node`/`card`/`done`/`error` 的现有字段，新增：

```json
{"type":"recall","nodes":[{"id":"save_money","label":"攒钱","domain":"labor"}],
 "edges":[{"source":"save_money","target":"new_pc","rel":"为了"}]}
{"type":"affair","action":"create","affair":{"id":"xikesong","title":"…","stage":"planning"}}
{"type":"action","kind":"reminder","ok":true,"detail":"已加 3 条提醒","payload":{}}
{"type":"memory","added_nodes":[{"id":"accordion","label":"手风琴","domain":"aesthetics"}],
 "added_edges":[{"source":"piano","target":"accordion","rel":"联想到"}],
 "updated":[{"id":"piano","label":"钢琴"}],"note":"记下了：钢琴 ↔ 手风琴"}
```
事件顺序（plan 通道）：
`mode` → `recall` → `affair`(create/update) → `plan` → `node`* → `action`* → `card` → `done` → `memory`
chat 通道：`mode` → `recall` → `token`* → `done` → `memory`

**`memory` 在 `done` 之后**（这是刻意的）：回复文本要先全部显示完，后端才去做 2–3 秒的记忆抽取，否则界面会白等。因此前端**必须读到 HTTP 流真正关闭**才停止消费，`done` 只作为"文本结束"的 UI 信号（撤打字指示、解锁输入框），不得 break 或 abort reader。
抽取失败就不发 `memory` 事件，不影响回复。
